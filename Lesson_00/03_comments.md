You might be used to single line comments **_and_** multi-line comments.  
In Python that's:
``` python
# This is a single line comment

# This is a
# multi line
# comment - that's comment humour for you, we actually
#           only have the single line comment

# notice how there is a '#' symbol followed by a space and then the
# comment content.
# Also notice how I was fine to use the '#' symbol in a comment
```
If you want to have a comment after some code:
``` python
my_int = 1  # in that case, you two spaces before the '#'
```

PEP8 says [all comments wrap at 72 chars](https://peps.python.org/pep-0008/#maximum-line-length)
